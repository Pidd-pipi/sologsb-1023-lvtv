# 校异斋 · 多版本文本自动比对与人工校勘工具

面向古籍和长文本编辑的多版本校勘工作台。可导入同一作品的不同版本，自动按段落与句子对齐，再由人工修正错位、判断增删改并导出校勘记。

## 功能

- 导入或粘贴同一作品的不同版本，按空行分段，再按句末标点切句。
- 自动对齐按 24 个句段一组让出浏览器主线程，长文本处理期间持续显示进度。
- 比较规则可忽略标点或常见异体字；规则变化会重算相同、改动和疑错位状态，不改写原文。
- 人工可交换邻近底本句的配对关系、整行移动、手动标记相同/改动/新增/删减/误错位。
- 每次确认都留档：**处理人署名、确认依据、确认时刻两侧正文与配对、差异判断和规则状态**。依据与署名缺一不可。
- 确认之后，只要两侧正文/配对、比较规则、判断类别或校记来源任一项变化，该行自动回到**待复核**，并显示具体原因；旧确认记录原样保留，重新确认时旧记录转为已失效。
- 批量确认只覆盖**当前搜索与筛选结果**中已写明依据的差异行，未写依据的跳过并计数；`A` 键可执行。
- 重新自动对齐时，确认档案按“底本句段 × 参校句段”配对续接；接不上的档案归入已失效/归档区继续留痕。
- 支持跳转到下一处待复核/待处理差异，以及键盘操作：`Alt+↓` 下一处、`A` 批量确认、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Y` 或 `Ctrl/⌘+Shift+Z` 重做。
- 最多保留 50 步撤销历史；版本、规则、对齐行、校记、确认档案和当前位置自动保存在 `localStorage`，关掉页面再打开可继续。旧版 `accepted` 草稿会迁移为“待补录处理人与依据”的待复核档案。
- 导出 Markdown 校勘记或完整 JSON 校勘数据，两者都分别标出**有效 / 待复核 / 已失效（含归档）**的确认，并附处理人、依据、确认时间与现场快照。
- 桌面三栏工作区，窄屏自动堆叠；提供读屏可识别的表头、标签、状态与按钮名称。

## 技术栈

- Vue 3 + Vite + TypeScript
- Arco Design Vue 2
- 浏览器 localStorage
- 无后端服务，全部计算在浏览器本地执行

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的 Vite 地址。源码未硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

类型检查和生产产物会生成到 `dist/`。可用 `npm run preview` 预览。

## 逻辑测试

```bash
npm run test:logic
```

用 esbuild 打包后在 Node 中驱动校勘核心逻辑，覆盖确认留痕、待复核触发（正文/配对、规则、校记、判断类别）、批量确认的依据与署名限定、重对齐续接与归档、旧版迁移、关页重开持久化以及两种导出的状态标注。

## Docker

```bash
docker build -t sologsb-1023 .
docker run --rm -p 10023:80 sologsb-1023
```

容器内 nginx 监听 `80`，根据根端口表映射到宿主 `10023`。

## 数据说明

版本正文、对齐结果、校勘说明、确认档案（含历次已失效记录与归档）和撤销记录均保存在当前浏览器。清除站点数据会删除草稿，建议定期导出 JSON 或 Markdown 校勘记。

确认档案分三种状态：

- **有效**：自确认以来，确认时记录的两侧正文与配对、规则、判断类别、校记来源均未变化。
- **待复核**：上述任一项后来发生变化（或由旧版迁移待补录），需要重新核对；旧档案仍完整保留。
- **已失效**：被重新确认取代、手动撤回，或重新对齐后原配对消失而归档。
