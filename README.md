# 校异斋 · 多版本文本自动比对与人工校勘工具

面向古籍和长文本编辑的多版本校勘工作台。可导入同一作品的不同版本，自动按段落与句子对齐，再由人工修正错位、判断增删改并导出校勘记。

## 功能

- 导入或粘贴同一作品的不同版本，按空行分段，再按句末标点切句。
- 自动对齐按 24 个句段一组让出浏览器主线程，长文本处理期间持续显示进度。
- 比较规则可忽略标点或常见异体字；规则变化会重算相同、改动和疑错位状态，不改写原文。
- 人工可交换邻近底本句的配对关系、整行移动、手动标记相同/改动/新增/删减/误错位。
- 每条差异可填写校勘说明（作为确认依据）和来源；确认时记录处理人、依据及当时两侧正文、类别与比较规则快照。
- 确认后若补改校记、挪动配对、改变判断类别或比较规则、重新对齐，该行自动回到**待复核**，行上的有效标记熄灭；旧确认记录（含失效原因与时间）始终保留，撤回或重新确认只把旧记录归档为**已失效**。
- 批量确认只覆盖当前搜索结果中已写明依据、且尚无有效确认的条目；无依据条目会跳过。
- 可按「待处理 / 待复核 / 确认有效 / 已失效留痕」筛选，并跳转到下一处待复核差异。
- 键盘操作：`Alt+↓` 下一处待复核、`A` 确认勾选中有依据的条目、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Y` 或 `Ctrl/⌘+Shift+Z` 重做。
- 最多保留 50 步撤销历史，版本、规则、对齐行、校记、处理人、确认记录和当前位置自动保存在 `localStorage`，关掉页面再打开可接着处理；旧版本草稿的已接受标记会迁移为待复核。
- 导出 Markdown 校勘记（含处理人、确认状态、待复核原因及已失效确认归档）或完整 JSON 校勘数据（每行带 `active/stale/void/none` 状态与分类统计）。
- 桌面三栏工作区，窄屏自动堆叠；提供读屏可识别的表头、标签、状态与按钮名称。

## 技术栈

- Vue 3 + Vite + TypeScript
- Arco Design Vue 2
- 浏览器 localStorage
- 无后端服务，全部计算在浏览器本地执行

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的 Vite 地址。源码未硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

类型检查和生产产物会生成到 `dist/`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1023 .
docker run --rm -p 10023:80 sologsb-1023
```

容器内 nginx 监听 `80`，根据根端口表映射到宿主 `10023`。

## 数据说明

版本正文、对齐结果、校勘说明和撤销记录均保存在当前浏览器。清除站点数据会删除草稿，建议定期导出 JSON 或 Markdown 校勘记。
